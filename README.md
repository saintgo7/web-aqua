# 스마트팜 제어 시스템

## 개요
이 프로젝트는 아두이노와 라즈베리 파이를 활용한 스마트팜 자동 제어 시스템입니다.

## 시스템 구성

### 하드웨어
- **아두이노**: 센서 데이터 수집 및 시리얼 통신
  - pH 센서
  - DHT22 온습도 센서
  - 조도 센서 (CdS)
  - 토양 수분 센서

- **라즈베리 파이**: 메인 컨트롤러
  - 데이터 수집 및 저장
  - 자동 제어 로직
  - 웹 서버 운영

- **액추에이터**
  - 워터 펌프 (릴레이 제어)
  - LED 조명 (릴레이 제어)
  - 환풍기 (릴레이 제어)

### 소프트웨어
- `arduino/`: 아두이노 센서 제어 코드
- `raspberry_pi/`: 라즈베리 파이 메인 제어 프로그램
- `web/`: 웹 대시보드
- `data/`: 센서 데이터 저장
- `logs/`: 시스템 로그

## 설치 방법

### 아두이노 설정
1. Arduino IDE 설치
2. DHT 센서 라이브러리 설치
3. `arduino/smartfarm_sensors/smartfarm_sensors.ino` 업로드

### 라즈베리 파이 설정
```bash
# 필수 패키지 설치
sudo apt-get update
sudo apt-get install python3 python3-pip

# Python 라이브러리 설치
pip3 install -r requirements.txt

# 프로그램 실행
python3 raspberry_pi/main.py
```

## 웹 대시보드
- 주소: http://[라즈베리파이_IP]:5000
- 실시간 센서 데이터 모니터링
- 수동 제어 기능
- 자동 제어 설정

## 자동 제어 기준
- **pH**: 5.5-6.5 범위 유지 (경고 알림)
- **온도**: 18-28°C 범위, 초과 시 환풍기 작동
- **습도**: 60-80% 범위 유지
- **토양 수분**: 40% 이하 시 워터 펌프 작동
- **조도**: 300 lux 이하 시 LED 점등
